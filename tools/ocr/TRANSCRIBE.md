# 몬몬 시트 받아쓰기 규칙

`data/monmon/sheets/<번호>.png` 한 장 = 몬몬 한 마리. 위에서부터 ① 등급·이름·별·레벨 ② 역할·거리·속성 줄 ③ 스탯 8칸 ④ 스킬 팝업 — 등급마다 개수가 다름: 전설·에픽 4개(기본공격 → 스킬 → 패시브★3 → 패시브★5), 레어 3개(기본공격 → 스킬 → 패시브★3), 고급·일반 2개(기본공격 → 스킬).

팝업은 게임에서 스크롤되는 창이라 아래가 잘려 있을 수 있다(맨 아래 줄이 흐리게 사라짐). 잘린 팝업은 보이는 데까지만 적고 `issues`에 "<스킬 이름> 아래 잘림"을 적는다.

**보이는 글자만 옮긴다. 추측해서 채우지 않는다.** 읽을 수 없거나 잘린 칸은 `null`로 두고 `issues`에 이유를 적는다.

## 출력: `data/monmon/json/<번호>.json`

```json
{
  "no": "001",
  "name": "마도리",
  "grade": "전설",
  "stars": 5,
  "maxLevel": 50,
  "role": "공격",
  "range": "원거리",
  "element": "암석",
  "stats": { "hp": 6700, "atk": 556, "def": 469, "spd": 102, "critRate": 15, "critDmg": 50, "effRes": 30, "effAcc": 0 },
  "skills": [
    {
      "slot": "기본공격",
      "name": "마법 투석",
      "cooldownTurns": null,
      "desc": "가까운 적 1명에게 피해를 입히고, 4% 확률로 1턴 간 [효과저항 -50%], [방어력 -60%] 디버프를 부여한다.",
      "damageBase": "자신의 공격력",
      "effects": [ { "name": "효과저항 감소 (강)", "turns": 1 }, { "name": "방어력 감소 (강)", "turns": 1 } ],
      "levels": [ "LV 2 피해량 +5%" ]
    }
  ],
  "issues": []
}
```

- `slot`: 팝업 왼쪽 위 꼬리표 그대로 — `기본공격` / `스킬` / `패시브`. 패시브 두 개는 순서대로 3번째·4번째.
- `cooldownTurns`: 모래시계 "대기시간 N턴"이 있으면 N, 없으면 null.
- `desc`: 설명 본문 전체를 줄바꿈 없이 한 줄로. 대괄호 `[...]`와 "4턴에 한 번" 같은 소제목 줄도 그대로 포함 (소제목은 `[4턴에 한 번]`처럼 앞에 붙여 구분).
- `damageBase`: "피해량 기반: [ ... ]"의 대괄호 안. 없으면 null.
- `effects`: 팝업 아래쪽 아이콘 목록의 이름과 시계 숫자(지속 턴 `turns`). 모래시계 숫자도 있으면 `cooldownTurns`(그 효과의 대기시간 — "5턴에 한 번" 같은 효과), 없으면 null. 이름은 `data/effects/effects.json`의 `name` 중 하나와 정확히 같아야 함 (예: "독 (강)", "기절"). 목록에 없는 이름이면 보이는 그대로 적고 `issues`에 적는다.
- `levels`: "LV n ..." 줄을 보이는 그대로. 잠금 아이콘은 무시.
- 스탯: 숫자만 (쉼표·% 빼고). 순서 = 체력, 공격력, 방어력, 속도 / 치명확률, 치명피해, 효과저항, 효과명중.
- 역할·거리·속성 줄이 툴팁에 가려 안 보이면 null + issues.
