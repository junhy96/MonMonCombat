# 문항 1 재설계안 (초안): 글라틀 — 얼음 요새

진단은 `data/dungeons/README.md` 「문항 1 후보: 글라틀」. 숫자(K, N, t, 균열 %)는 시뮬레이션으로 맞출 자리이고, 지금은 방향만 정한다.

## 지금 구조의 문제 (요약)

| # | 문제 | 원인 |
|---|---|---|
| 1 | 다회 몬몬 2명 이상이 있어야 하고, 한 명이 쓰러지면 무너진다 | 등껍질이 보스 스킬마다 **가득(60~90)으로 다시** 생김. 못 깨면 [빙하 분출] 피해 + 보스 회복 → 다음 주기가 더 불리 |
| 2 | 열쇠 몬몬을 키워도 깨는 속도가 그대로 | 등껍질은 **맞은 횟수**로만 깨지고, 성장(레벨·별·스킬 레벨)으로 타수가 늘지 않음. 7단계부터 횟수만 70~90으로 오름 |
| 3 | 실제 승부는 열쇠가 아닌 고화력 몬몬이 냄 | 등껍질 중 피해 −80% → 체력은 [탈진] 동안만 깎임. 탈진 길이는 속도와 무관하게 고정 → "고정된 창에 몰아치기" = 고화력 몬몬 몫 |
| 3' | 디버프·속도로 돕는 길도 막혀 있음 | [빙하 각성]이 디버프 전부 제거 + 속도 +15% → 탈진 중 건 디버프가 지워지고 다음 주기가 빨라짐 |

## 목표

- **열쇠(다회 피해)를 키우면 클리어가 쉬워진다** — 성장 축과 열쇠 효과를 잇는다
- **한 명이 쓰러져도 바로 무너지지 않는다** — 실패가 쌓여 악순환이 되지 않게
- **탈진 창의 주역에 열쇠 몬몬도 들어간다** — 고화력 몬몬과 역할을 나눠 가짐
- 보스 정체성(얼음 등껍질을 두드려 깨는 보스)은 그대로

## 바꾸는 것

### ① 균열이 남는다 — 문제 1
- 지금: 보스 스킬 후 등껍질이 **가득(60~90)**으로 다시 생김
- 바꿈: 깨지지 않은 채로 스킬을 쓰면 남은 횟수에 **+K만 더하고 상한 N**. 깨진 뒤 다시 두를 때만 가득
- 효과: 못 깨도 때린 만큼은 남는다. 한 명이 쓰러져도 다음 주기에 이어서 깸. [빙하 분출](남은 횟수 비례 피해)은 그대로라 실패의 벌은 남음

### ② 강한 타격은 더 센다 — 문제 2
- 바꿈: 한 타의 피해(80% 감소 후)가 **보스 최대 체력의 t% 이상이면 2번**으로 센다
- t는 단계별 보스 체력에 맞춰 정한다 → 그 단계 곡선을 따라 키운 다회 몬몬일수록 빨리 깸
- 7단계부터 횟수를 60 → 70~90으로 올리는 대신 **t를 올려** 난이도를 표현 — "더 많이 때려라"가 아니라 "더 키워라"가 되게
- 효과: 열쇠 몬몬의 레벨·별·스킬 피해량 강화가 깨는 속도로 바로 이어짐

### ③ 탈진 중 균열 — 문제 3
- 바꿈: [탈진] 동안 받은 타격 1번마다 **[얼음 균열] 받는 피해 +x%** (상한 있음, 탈진이 끝나면 사라짐)
- 효과: 다회 몬몬이 탈진 창에서 고화력 몬몬의 피해를 키워 주는 역할을 맡음 → 열쇠는 "여는 도구"에서 "창의 한 축"으로

### ④ 빙하 각성 조정 — 문제 3'
- 바꿈: [속도 +15%]는 **등껍질이 깨지지 않은 채 스킬을 쓸 때만** 붙는다 (디버프 제거는 그대로)
- 효과: 열쇠를 잘 써서 깬 플레이는 벌받지 않고, 실패했을 때만 다음 주기가 빨라짐

### 공략 문구 (화면)
- 초반: "여러 번 때리는 몬몬으로 [얼음 등껍질]을 깨세요. 못 깨도 금이 간 만큼은 남아요."
- 후반: "강하게 때릴수록 [얼음 등껍질]이 빨리 깨져요. [탈진] 중에 여러 번 때리면 [얼음 균열]이 쌓여 모두의 피해가 커져요."

## 시뮬레이션으로 확인할 것

| 확인 | 비교 | 성공 기준 |
|---|---|---|
| 성장 연결 | 열쇠 몬몬 레벨만 올린 팀 vs 열쇠가 아닌 몬몬 레벨만 올린 팀 | 재설계 후에는 열쇠를 키운 쪽의 클리어 턴이 더 줄어든다 (지금은 반대일 것으로 예상) |
| 무너짐 | 다회 몬몬 2명 중 1명을 n턴에 이탈시킴 | 지금: 그 뒤 등껍질을 못 깸 / 재설계: 늦어지지만 깸 |
| 열쇠 수 | 다회 몬몬 0·1·2·3명 | 1명으로도 (느리지만) 가능, 2명이면 안정 |
| 단계 | 1~20단계 보스 스탯 (`ice-fortress/boss-stats-full.csv`) | 단계가 오를 때 요구 성장(레벨·별)이 계단처럼 오른다 |

## 정해야 할 전투 규칙 (추측하지 않고 확인 필요)

- 보스·몬몬 스킬 에너지가 속도에 따라 어떻게 차는가 (턴당 양, 행동 순서)
- [탈진]이 몇 턴(또는 몇 행동) 가는가 — "일정하게 찬다"의 실제 양
- 탈진이 풀리며 "바로 쓰는 스킬"은 정해진 순서인가, 무작위인가
- 다회 피해의 1타마다 등껍질 횟수가 1씩 깎이는가 (공략 문구 "60번을 맞혀"로 보아 그렇게 보이나 확인 필요), 기본공격·패시브 추가타·[빙하 분출] 반사 등도 세는가
- 웨이브 1~2(잡몹) 구성과 보스전까지 남는 체력·에너지
