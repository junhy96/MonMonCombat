## 공통으로 보이는 것

- 9개 중 8개가 **후반에 "열쇠 2명 / 여러 명 / 번갈아"**를 안내한다 — 열쇠 한 명의 효과가 보스 행동 주기를 덮지 못하게 되어 있음
- 열쇠 효과가 **확률(효과명중 vs 보스 효과저항)**에 묶인 보스가 많고(카니보·마리엘·볼트피온·윈드윙 후반), 단계가 오를수록 보스 효과저항이 오른다
- 보스가 **열쇠를 직접 무력화**하는 장치: 울피(버프 제거), 볼트피온(스킬마다 디버프 제거 + 아군 효과명중 −25%), 빙하 각성(디버프 제거), 악몽 폭발(치유 몬몬 2배 피해)
